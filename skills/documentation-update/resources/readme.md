# Resource: README.md

**What it documents**: Short project entry point with the current release summary, a brief capability overview, and the documentation index.

**Source of truth**: The project as a whole; README is only an index and summary page.

**Single-source-of-truth rules**:
- API schemas and endpoint details live in `docs/API_REFERENCE.md`.
- Hardware assembly and flashing live in `docs/SETUP_README.md` and `docs/ESP32_UPLOAD_README.md`.
- Wiring lives in `docs/WIRING_README.md`.
- Architecture and module detail live in `AGENTS.md`.

**Update when**:
- A new documentation file is added.
- The project description or documented capabilities change.
- The hardware summary or release summary changes.

**Do NOT update for**: API schemas, wiring details, upload steps, or WiFi strategy details.
